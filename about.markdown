I'm Ly-sec. This is where I write about Linux, security and open source software.

The posts cover tools I use, projects I work on, and problems I run into along the way. There are Linux distribution experiments, development notes and security findings.

You can find my code on [GitHub](https://github.com/Ly-sec). To follow new posts, add the [RSS feed](/feed.xml) to your reader.
